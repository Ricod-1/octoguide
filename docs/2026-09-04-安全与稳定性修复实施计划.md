# Security Stability Build Fixes Implementation Plan

> **For agentic workers:** Execute the checklist task-by-task and verify each change before moving on.

**Goal:** Remove exposed credentials and unsafe network behavior, bound server work, make knowledge writes idempotent, and restore frontend/backend verification.

**Architecture:** Keep existing Spring MVC and Vue/Vite structure. Add narrowly scoped validation/configuration at the controller and research boundaries, use Spring's bounded executor for streaming work, and use a database atomic insert-ignore path for remembered knowledge.

**Tech Stack:** Spring Boot 2.7, MyBatis, MySQL, JUnit 5, Vue 3, Vite, Vitest.

**Files:** `backend/src/main/resources/application-local.yml`, `backend/src/main/java/com/octoguide/ai/WebResearcher.java`, `backend/src/main/java/com/octoguide/knowledge/service/KnowledgeCollector.java`, `backend/src/test/java/com/octoguide/ai/WebResearcherTest.java`.

- [ ] Add failing tests for rejecting non-GitHub/private URLs and oversized HTTP responses.
